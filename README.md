# PIXELREALM

A browser-based pixel-art world simulator prototype. Build and observe a living world with five realms, editable terrain, territory expansion, settlement placement, world chronicles, and downloadable save files.

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies are required.

## Prototype features

- Procedurally generated tile map and five kingdoms
- Play, pause, step-by-year, and simulation speed controls
- Terrain editor for forests, mountains, and water
- Settlement placement and manual territory claims
- Kingdom population, treasury, military, and stability panels
- Simulation events and historical chronicle
- Export/import worlds as JSON files

## Current limitations

This is an early client-side prototype. Diplomacy, dynasties, detailed combat, trade routes, and online accounts/community features are not implemented yet. Save files are downloaded/imported locally; there is no cloud backend.
